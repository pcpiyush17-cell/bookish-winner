# Quantitative research workspace

This tree is isolated from WP-14 and all operational trading state. Version-controlled experiment
definitions may be added under `research/experiments/`. Generated datasets, caches, results, model
weights, and mutable state are excluded from Git and must carry their own immutable manifests and
checksums.

No research artifact can authorize paper, shadow, or production execution. Read
[`docs/QUANT_RESEARCH_GOVERNANCE.md`](../docs/QUANT_RESEARCH_GOVERNANCE.md) before adding a research
workflow.
